### LinkedIn 2: MCP (week 2, with article 2)

> MCP (Model Context Protocol) is now how AI agents get their tools. I track 137 MCP and tool-integration projects. The three I'd start with:
>
> 1. The official servers (GitHub, Playwright, the reference set): maintained by the people who own the API.
> 2. Composio, if you need many SaaS integrations with auth handled for you.
> 3. A2A, once you have several agents that need to hand work to each other. MCP connects agents to tools; A2A connects agents to agents.
>
> One warning: an MCP server runs with whatever access you give it. Read community servers' code before connecting them to anything sensitive.
>
> Full ranking and write-up in the first comment.
>
> #MCP #AIAgents #LLM

### LinkedIn 3: memory (week 3, with article 3)

> "Agent memory" means three different things, and most teams pick a tool before deciding which one they need:
>
> 1. A map of your code (knowledge graphs for coding agents)
> 2. Continuity across sessions (what did we decide yesterday?)
> 3. A memory service for your product's agents (users, preferences, past tasks)
>
> I ranked 117 open-source memory tools by GitHub stars. The leaders are split across all three ideas; nobody has won yet.
>
> My advice: decide which memory you need, start simple, and measure. Memory that doesn't change outcomes is just cost.
>
> Write-up in the first comment.
>
> #AIAgents #LLM #OpenSource
