# Workspace

Working files behind the list: how candidates were collected, classified and audited, plus the promotion plans. Nothing here is read by the website build.

- `phase2/` - candidate collection, classification and gateway verification for the Phase 2 expansion.
- `reaudit-2026-11/` - the November 2026 re-audit: scripts, per-chunk results and reports.
- `audit-results/`, `audit-gw/`, `audit-gw.log`, `dead-and-stale-repos.csv` - output of earlier audits.
- `agents/` - the Claude Code agent definitions used for classification, judging and gateway verification.
- `marketing-plans/`, `content-kit/`, `promotion-strategy.md` - promotion plans and draft posts.

The scripts were written to run from the folder above the repository, with `phase2/` and `reaudit-2026-11/` beside `awesome-ai-agent-stack/`. Copy them back to that layout, or adjust the paths, before running them. The copies of third-party awesome lists that `phase2/h_work/` cached are not included.
