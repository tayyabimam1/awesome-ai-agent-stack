# Contributing

Thanks for helping keep this list useful.

## Rules for a new entry

- You have personally used the tool, or can vouch for it. This is a curation, not a directory.
- The project is actively maintained (commit in the last 6 months) and has a README that explains what it does.
- It fits an existing layer of the stack. If it needs a new section, open an issue first.
- One entry per pull request, unless you are adding a whole new section.

## Format

```
- [owner/repo](https://github.com/owner/repo) - One-line description ending in a period.
```

- Keep descriptions under ~100 characters and say what it *does*, not how great it is.
- Place the entry in the sub-group of the section where it fits; no need to sort alphabetically.
- No star counts, badges, or emoji in entries.
- Run a spell check.

## Removals

Open a PR titled `Remove owner/repo` and say why (archived, unmaintained, replaced by something better).
